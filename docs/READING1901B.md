# 1901年、参謀本部から福島少将への起案5通：表と読み

English: [READING1901B.en.md](READING1901B.en.md)

## 方式
- 体裁は着電（[READING1901.md](READING1901.md)）と同じ。欧文電報（ローマ字の日本語）の中で、機密の語だけを数字2桁＝カナ1字に換え、5桁ずつに区切る。数字の連なり23本はどれも偶数桁。
- 表は着電の表とは別で、**十の位＝段、一の位＝行の格子**。

| | 十の位 | 一の位 |
|---|---|---|
| 前半 01〜50 | 0 ア段、1 イ段、2 ウ段、3 エ段、4 オ段 | 1 ア、2 カ、3 ガ、4 サ、5 ザ、6 タ、7 ダ、8 ナ、9 ハ、0 バ（バ行は 10・20・30・40・50） |
| 後半 51〜95 | 5 ア段、6 イ段、7 ウ段、8 エ段、9 オ段 | 1 パ、2 マ、3 ヤ、4 ラ。55＝ワ、65＝ン |

- 例：ア01 カ02 バ10 シ14 ウ21 オ41 ノ48 ボ50 パ51 マ52 ワ55 ミ62 リ64 ン65 ヨ93。
- 助詞の「ヲ」は オ（41）で打つ。
- 字音は当時の綴りどおり：条約＝ゼウヤク、張＝テウ、帰朝＝キテウ、忠告＝チウコク、膠州＝コウシウ。
- 電報に出てくる値は53種類。うち48種類が上の表にあり、**59・60・80・89・99 の5つ（10か所）は表にない**。どれも後半の一の位 9・0 で、語の符号（下の「語の符号」）。
- 表のうち電報に出てこない値（22個）は、格子の規則から置いたもので、電報では確かめていない。後半の一の位 6〜8 と 75・85・95 の使い方は分からない。

## 語の符号
| 値 | 語 | 出てくる所 | 根拠 |
|---|---|---|---|
| 99 | 露 | `[99][50]ミツ…ノ 不利益ナル`、`[99][60]ゼウハ` | 文脈（露清密約、露清条） |
| 60 | 清 | 同上、`リコウシヨウハ[60][80]ヲシテ` | 文脈と下の史料 |
| 80 | 公使 | `[60][80]ヲシテ`、`[89][80]ノ`、`[80]ガ` | 下の史料 |
| 89 | 独（推定） | `[89][80]ノ…如何ニ彼ヲ引キ受クルカ` | 1か所だけ。元帥（ワルデルゼー）の国の公使とみる |
| 59 | 政府（推定） | `[60][80]ヲシテ[59]ニ告ゲサスル`、`我ガ[59]ニ張之洞ヨリ` | 文脈。外務省・外務大臣でも文は通る |

- **史料**：外務省記録「外務大臣ノ会談要領雑件 第二巻」の、明治34年3月1日・4日の清国公使来談要領筆記（JACAR B03030000800、コマ0061）に「三月一日 在本邦清国公使来省、慶親王及李鴻章ヨリ電報ニ接セリトテ其写ヲ示ス」とある。3月2日の電報 C09122809400 の「李鴻章ハ[60][80]ヲシテ[59]ニ告ゲサスルニ」は、その翌日にこの件を伝えたもの。同じ巻の目次（B03030000700、コマ0053〜0054）に「対露警告ノ義帝国ニ懇請方ニ関スル劉張来電」とあり、電報の「張之洞ヨリ此ノ条約ノ成リ立タヌ様ニト頼ミ来レリ」と合う。目次は相手を「清公使」「独公使」と略して書く。
- 5月1日の電報の `[80]ガ` については、同じ日の山口中将あての起案（C09122812200、目録の翻刻）に「政府ハ減兵ニツキ其意見ヲ小村公使ヘ電報セリ」とある。
- 5つの語の頭の字（ロ・ド・コ・シ・セ）はイロハ順で、値は 99・89・80・60・59 と下がる。語をイロハ順に並べて後ろから番号を振った表と合う（語を当てた後に気づいた並びで、59 を 外務省 とすると崩れる）。
- 同じ綴（通報綴）の目録を C09122807700〜C09122816000 の84件引いた。福島少将あての「暗号電報」はこの5通だけ。

## 読み
[ ] は表にない値（語の符号）。〔 〕は表にある値だが語として確かでない字。ローマ字の部分は、数字が読めてから読み直した綴りを含む（1回目の書き起こしは [data/outgoing1901.txt](../data/outgoing1901.txt)）。出典はどれも JACAR、防衛省防衛研究所、参謀本部 雑『自明治３４年１月５日至同年６月２９日 通報綴』。当時の訳文は見つかっていない。

### C09122808300（1901年2月、日付なし。コマ0306–0307）
| 数字 | 表での読み |
|---|---|
| `02624 14832 4221` yurusazu | カミオノ〔ケ〕コウ（許サズ） |
| `1982 1518` yarutumori | ヒメジニ（遣ル積リ） |

神尾ノ〔ケコウ〕許サズ、姫路ニ遣ル積リ。32（ケ）は画像でもはっきり 32。ケコウ は ケンコウ（健康）の ン（65）の落ちとみる（推定）：同じ綴の2月20日の起案（C09122808700、目録の翻刻）に「石橋ノ健康ハ略ホ復シタレト渡清ハ六ツカシ故ニ連隊長ニシタシ」と同じ言い回しがある。神尾光臣は1901年2月に第10師団（司令部は姫路）の参謀長になっている（日本語版ウィキペディア「神尾光臣」）。

### C09122809400（1901-03-02。コマ0331–0332）
| 数字 | 表での読み |
|---|---|
| `99506 22652 2248` furiekinaru | [99]〔ボ〕ミツ〔マ〕クノ（不利益ナル） |
| `5503` tiukokunitaisi | ワガ（忠告ニ対シ） |
| `64422 11493 2109 6080` osite | リコウシヨウハ[60][80]（ヲシテ） |
| `5918` tugesasuruni | [59]ニ（告ゲサスルニ） |
| `99603 52109` motukano… riekito kangoureba | [99][60]ゼウハ（目下ノ…利益ト考フレバ） |
| `43962 14222 09118 40306` kii omotte… | ゴ〔チ〕ウコクハイレガタ（キ意ヲ以テ…） |
| mata waga `5918 36211 44721` yorikono | [59]ニテウシドウ（ヨリ此ノ） |
| `35215 32248` naritatanuyoo nito tanomi kitareri | ゼウヤクノ（成リ立タヌ様ニト頼ミ来レリ） |
| mata `34110 16598 6492` onadi imino | セイアン〔ヨ〕リモ（同ジ意味ノ） |
| `37659 12112` tari Tamura | デンポウキ（タリ） |

露〔清〕密約ノ不利益ナル我ガ忠告ニ対シ、李鴻章ハ清公使ヲシテ[政府?]ニ告ゲサスルニ、露清条ハ目下ノ…利益ト考フレバ御忠告ハ容レ難キ意ヲ以テ…。又我ガ[政府?]ニ張之洞ヨリ此ノ条約ノ成リ立タヌ様ニト頼ミ来レリ。又西安ヨリモ同ジ意味ノ電報来タリ。田村。（欄外に「此電報ノ全文ヲ山口師団長ニモ送ラレタシ」）

- 最初の群は 99506 とみる。1回目の読みは 99506、2回目の読み手（Codex）は本文欄の全体では 77306、この行だけの切り出しでは 99506、3人目の読み手（Claude Sonnet）も 99506。JACAR の目録の翻刻は 99606。50 は ボ で語にならず、後ろに `[99][60]ゼウ` があるので、60（清）の書き誤りで「露清密約」とみる（推定。読みに数えない）。
- 22652 の 52 は マ。ヤ（53）なら「ミツヤク」（密約）になる。画像では 2 に見える。1桁違いの書き誤りとみる（推定）。
- 〔チ〕と〔ヨ〕は、表が分かってから 43962→43162、16598→16593 と読み直した桁。2回目の読み手は表を知らずに 43962・16598 と読んだので、推定として扱い、読みに数えない。切り出しで読み直させても、Codex は 4396{2/4}・96598、Sonnet は 43{6/5}…・16598 で、支持されなかった。

### C09122810100（1901-03-08。コマ0348–0350）
| 数字 | 表での読み |
|---|---|
| `33652 41109 42211 42155 65936 41849 6518` kitaru nozomi{o/a} | ゲンスイハコウシウワンヨリニホンニ（来タル望ミ…） |
| `92168 98048` te?oriikani | 〔モチ〕[89][80]ノ（…如何ニ） |
| `02844 11912` ukurukao saguritiunari | カレオヒキ（受クルカヲ探リ中ナリ） |
| `55840 94421` tooni hikiukuru | ワレハソウ（当ニ引キ受クル） |
| `93212 40884 09626 57321` wo susumerareyo Tamura | ヨウスナレハ〔ミ〕ンユウ（ヲ勧メラレヨ） |

元帥ハ膠州湾ヨリ日本ニ来タル望ミヲ〔持チ〕、[独?]公使ノ〔手ヨリ〕如何ニ彼ヲ引キ受クルカヲ探リ中ナリ。我ハ相当ニ引キ受クル様子ナレバ〔漫〕遊ヲ勧メラレヨ。田村。

- 1本目の3群目と4本目の2群目は、1回目の読みが 42291・94427。表が分かってから 42211・94421 と読み直した。2回目の読み手（Codex）は表を知らずに 42211・94421 と読んだ。
- 数字の前後のローマ字は読みが割れている。1本目の後ろは nozomio（Claude の読み直し、Codex の切り出しの読み、JACAR の目録の翻刻）か nozomia（Sonnet）。2本目の後ろは teyoriikani（Claude の読み直し、Codex の切り出しの読み）、tezoriikani（Sonnet）、tugoiikani（Codex の本文欄全体の読み）。nozomio・teyori なら「望ミヲ持チ」「手ヨリ」で モチ が語になるが、割れているので モチ は読みに数えない。
- 09626 の 62 は ミ。マ（52）なら「マンユウ」（漫遊）になる。画像では 62 に見える。1桁違いの書き誤りとみる（推定）。同じ綴の起案 C09122808100 に「帰途日本ヘ来遊スルコト」とある。
- 「元帥」はドイツのワルデルゼー元帥とみる。4月22日の福島少将の着電（C09122801000）に「元帥ガ日本ヘ行クコトハ皇帝ヨリ許可ヲ得タリ」とある。

## 数
| 電報 | 組 | 表にある値 | 読みに数える組 | 2回目の読み手との桁の一致 |
|---|---|---|---|---|
| C09122808300 | 11 | 11 | 10（90.9%） | 22/22 |
| C09122808400 | 15 | 15 | 15（100%） | 30/30 |
| C09122809400 | 59 | 52 | 53（89.8%） | 109/118（92.4%。2桁の組では 53/59＝89.8%） |
| C09122810100 | 42 | 40 | 38（90.5%） | 82/84（97.6%） |
| C09122812300 | 21 | 20 | 21（100%） | 42/42 |
| 合計 | 148 | 138 | 137（92.6%） | 285/296（96.3%） |

- 「読みに数える組」は、表にある値のうち〔 〕の字（8組）を除いたもの（130組）に、史料の裏づけのある語の符号 99・60・80（7組）を足した数。推定の 89・59（3組）は数えない。
- したがって、**C09122808400 と C09122812300 は全文の読み、ほかの3通は部分的な読み**。対照と2回目の書き起こしの詳細は [METHOD.md](METHOD.md) §10。
