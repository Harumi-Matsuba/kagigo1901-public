# 1901年、参謀本部から福島少将への起案5通：表と読み

English: [READING1901B.en.md](READING1901B.en.md)

## 方式
- 体裁は着電（[READING1901.md](READING1901.md)）と同じ。欧文電報（ローマ字の日本語）の中で、機密の語だけを数字2桁＝カナ1字に換え、5桁ずつに区切る。数字の連なり23本はどれも偶数桁。
- 表は着電の表とは別で、**十の位＝段、一の位＝行の格子**。

| | 十の位 | 一の位 |
|---|---|---|
| 前半 01〜50 | 0 ア段、1 イ段、2 ウ段、3 エ段、4 オ段 | 1 ア、2 カ、3 ガ、4 サ、5 ザ、6 タ、7 ダ、8 ナ、9 ハ、0 バ（バ行は 10・20・30・40・50） |
| 後半 51〜95 | 5 ア段、6 イ段、7 ウ段、8 エ段、9 オ段 | 1 パ、2 マ、3 ヤ、4 ラ。55＝ワ、65＝ン |

- 例：ア01 カ02 バ10 シ14 ウ21 オ41 ノ48 ボ50 パ51 マ52 ワ55 ミ62 リ64 ン65 ヨ93。
- 助詞の「ヲ」は オ（41）で打つ。
- 字音は当時の綴りどおり：条約＝ゼウヤク、張＝テウ、帰朝＝キテウ、忠告＝チウコク、膠州＝コウシウ。
- 電報に出てくる値は53種類。うち48種類が上の表にあり、**59・60・80・89・99 の5つ（10か所）は表にない**。どれも後半の一の位 9・0 で、国名・役職などの語の符号とみられる（推定。[OPEN.md](OPEN.md)）。
- 表のうち電報に出てこない値（22個）は、格子の規則から置いたもので、電報では確かめていない。後半の一の位 6〜8 と 75・85・95 の使い方は分からない。

## 読み
[ ] は表にない値。〔 〕は表にある値だが語として確かでない字。ローマ字の部分は、数字が読めてから読み直した綴りを含む（1回目の書き起こしは [data/outgoing1901.txt](../data/outgoing1901.txt)）。出典はどれも JACAR、防衛省防衛研究所、参謀本部 雑『自明治３４年１月５日至同年６月２９日 通報綴』。当時の訳文は見つかっていない。
