# 1901年の数字のカナ暗号：表と電報ごとの対応

English: [READING1901.en.md](READING1901.en.md)

## 方式
- 欧文電報（ローマ字の日本語）の中で、機密の語（人名・地名・敬称など）だけを数字にする。数字は2桁でカナ1字。送るときは5桁ずつに区切るので、連なりの最後の群だけ4桁・3桁・2桁に短くなる（例：`00161 21108`＝5組、`45671 867`＝4組）。
- 表は、五十音を段ごとに並べ、濁音・半濁音を清音のすぐ後ろに挟んで、00 から順に番号を振ったもの。

| 番号 | カナ |
|---|---|
| 00〜14 | ア カ ガ サ ザ タ ダ ナ ハ バ パ マ ヤ ラ ワ |
| 15〜26 | イ キ ギ シ ジ チ ニ ヒ ビ ピ ミ リ |
| 27〜39 | ウ ク グ ス ズ ツ ヌ フ ブ プ ム ユ ル |
| 40〜52 | エ ケ ゲ セ ゼ テ デ ネ ヘ ベ ペ メ レ |
| 53〜67 | オ コ ゴ ソ ゾ ト ド ノ ホ ボ ポ モ ヨ ロ ン |

- 電報で実際に確かめられた値は38個（下の電報に出てくるもの）。残りの30個は、並びの規則から埋めた値で、電報では確かめていない。68〜99 の使い方は分かっていない（[OPEN.md](OPEN.md)）。
- 助詞の「ヲ」は オ（53）、「ハ」は ハ（08）か ワ（14）で書かれている。
