# 未解決の点

## 1. C09122806100（1901-02-18、広島）が読めない
- 数字の群4つ（S1 14桁・S2 2桁・S3 8桁・S4 6桁）。訳文と前後の平文から、S2＝ニ、S3＝ニンチワ、S4＝フクム と受け持ちは決まる。2桁で1カナとみると長さが合う。
- 試して合わなかったもの：1902年の表、1902年の表に周期1〜7の数字を足す方式（群ごとに鍵を始めからやり直す場合も）、どちらかの桁が母音を表す規則、イロハ順・五十音順の番号のずらし。
- 同じ ニ が 91 と 69 になる。15組の値はすべて違うので、1字に複数の値を割り当てる表（同音異字）と矛盾はしないが、それを確かめる力もない。
- 同じ方式の2通目は、明治34年の電報綴を全部画像で見ても見つからなかった。
- 数字の脇に薄い別筆の印がある。濁点か受信側の照合の印かは、二値化された画像では決められない。

## 2. C09122909900 が全文の読みに届かない
- 独立の2回目の最低値が 84.6%（Claude Sonnet、拡大画像の1回）。この回は、1列目の「三」の右下の小さな「エ」形の書き込みを本文の字として1つ入れ、2列目の頭と4列目の 八 も違う字に読んだ。ほかの回は 88.5〜100%。
- 2列目の頭の横画は、右端が墨の太い縦の帯に入って隠れる。一（ン＝10 の頭）か、フ・七かは画像では決められない。
- イ を 17（表では 19）と書いている。画像でも 七。書き手か送信の誤りとみる（推定）。

## 3. C03020059400 が全文の読みに届かない
- 訳文と合わないのが2組：09（平文 ハ なら 04）と 88（平文 ジ なら 68）。画像では 〇九 と 八八。
- 1列目の末の字は、同じ書き手の 九 と比べて縦画が直立し、右の画が丸く巻く。四 の可能性を疑い、Codex 2回・Sonnet 2回に見本と並べて判定させたが、4回とも第1候補は 九 だった。九 のままとし、訳文との不一致は書き手か送信の誤りとみる（推定）。
- 四 と決められれば訳文との一致は 11/12 になる。原本を見ないと決められない。
