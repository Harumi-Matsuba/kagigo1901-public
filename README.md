# 1902〜04年の日本陸軍の数字のカナ暗号（JACAR の電報）の表と読み

明治の陸軍が1902〜04年に国内の電報で使った、**数字2桁で仮名1字を表す暗号**の表を復元し、電報4通を読んだ記録です。表は「頭の数字＝五十音の段（母音）、後ろの数字＝行（子音）」の座標になっていて、同じ表が1902年3月（大阪）から1904年1月（小倉・門司）まで変わらずに使われていました。

English: [README.en.md](README.en.md)。SOURCES・METHOD・READING・OPEN・PRIOR_CHECK にも英語版（*.en.md）があります。

## 追加：1901年の発信側の表（2026-11-10）
- **状態：表の割り出しと、2通は全文の読み、3通は部分的な読み。** 参謀本部（田村少将）から北京の福島少将への起案5通（1901年2〜5月、Cyphersolver の目録 715）。当時の訳文は見つかっていない。2026-11-10 に調べた範囲（[docs/PRIOR_CHECK.md](docs/PRIOR_CHECK.md) の追加の節）では、先行の解読も平文の刊行も見当たらなかった。「初めて」とは言い切らない。
- **表**：2桁でカナ1字、十の位＝段、一の位＝行の格子。前半 01〜50 は 十の位 0〜4＝ア〜オ段、一の位 1ア 2カ 3ガ 4サ 5ザ 6タ 7ダ 8ナ 9ハ 0バ。後半 51〜95 は 十の位 5〜9＝ア〜オ段、一の位 1パ 2マ 3ヤ 4ラ、55＝ワ、65＝ン。着電の表（下）とは別の表。全体と読みは [docs/READING1901B.md](docs/READING1901B.md)。
- **読み**（[ ] は語の符号で ? は推定、〔 〕は確かでない字。語の符号は 99＝露・60＝清・80＝公使・89＝独?・59＝政府?）：
  - C09122808400（2月14日）：大島ノ事ハ今相談中、若シ行ケネバ楠瀬ハ如何、柴ハ兎ニ角返ス（全文の読み）
  - C09122812300（5月1日）：帰朝スル様ニ…ナレリ、又交代兵ノ数ハ[公使]ガ…ザレバ望ミヲ充タシ難シ（全文の読み。「…ザレバ」のローマ字は読みが割れている）
  - C09122808300（2月）：神尾ノ〔ケコウ〕許サズ、姫路ニ遣ル積リ（ケコウ は 健康 の ン 落ちとみる・推定）
  - C09122809400（3月2日）：[露]〔清〕密約ノ不利益ナル我ガ忠告ニ対シ李鴻章ハ[清][公使]ヲシテ[政府?]ニ告ゲサスルニ[露][清]条ハ…御忠告ハ容レ難キ意…、又我ガ[政府?]ニ張之洞ヨリ此ノ条約ノ成リ立タヌ様ニト頼ミ来レリ、又西安ヨリモ同ジ意味ノ電報来タリ
  - C09122810100（3月8日）：元帥ハ膠州湾ヨリ日本ニ来タル望ミ…〔モチ〕[独?][公使]ノ…如何ニ彼ヲ引キ受クルカヲ探リ中ナリ、我ハ相当ニ引キ受クル様子ナレバ〔漫〕遊ヲ勧メラレヨ
- **数字**：148組のうち表にある値 138組、読みに数える組 137（92.6%。電報ごとに 90.9%・100%・89.8%・90.5%・100%。史料の裏づけのある語の符号7組を含む）。数字を入れ替えた表との対照は1000回中0回（辞書の語で覆えるカナの数。本物 58、最大 37）。独立の2回目の書き起こし（Codex）との桁の一致は 285/296（96.3%）、電報ごとの最低は C09122809400 の 92.4%（2桁の組では 89.8%）。較正はない（[docs/METHOD.md](docs/METHOD.md) §10）。
- **読めていないもの**：表にない5つの値（59・60・80・89・99。語の符号とみられる）、C09122809400 の最初の群、語として合わない字（[docs/OPEN.md](docs/OPEN.md) §1b）。
- **人は書き起こしを確かめていない。** 書き起こしは AI による（1回目 Claude Fable 5.2、2回目 OpenAI Codex gpt-6-astra・推論 high、先行の調べ Claude Sonnet）。AI どうしの一致は、人の確認の代わりにならない。

## 追加：1901年の表（2026-11-10）
- **状態：表の復元。** 清国駐在の将校などからの電報7通（1901年2〜4月）で、機密の語だけを数字2桁＝カナ1字にした部分を、復元した表で読める。7通とも当時の訳文が同じ綴にあり、**電報は当時読まれていたもの**。ここで新しいのは表の復元で、2026-11-10 に調べた範囲（[docs/PRIOR_CHECK.md](docs/PRIOR_CHECK.md) の追加の節）では、この表の公表は見当たらなかった。「初めて」とは言い切らない。
- **表**：五十音を段ごとに並べ、濁音・半濁音を清音のすぐ後ろに挟んで、00 から順に番号を振る（ア00 カ01 ガ02 … ワ14、イ15 … リ26、ウ27 … ル39、エ40 … レ52、オ53 … ン67）。全体は [docs/READING1901.md](docs/READING1901.md)。1902〜04年の表（下）とは別の表。
- **数字**：表を決めた後に当てた2通（重慶の C09122796200 と、広島の C09122806100 の表の中の値だけの2本）で、訳文の語と 16/16 一致。表の68字を無作為に並べ替えた対照は1000回中0回（最大4）。独立の2回目の書き起こし（Codex）との桁の一致は 6通で 123/135（91.1%）、電報ごとの最低は C09122801000 の 75.0%（2回のうち低い方。[docs/METHOD.md](docs/METHOD.md) §9.3）。
- **C09122806100（1901-02-18）**：2026-10 の版で未読としていた電報。同じ表で ンチワ（任地ハ）・フクム（服務）・テンシヨク と読める。69・91 は表の外（[docs/OPEN.md](docs/OPEN.md)）。
- 参謀本部から福島少将への起案5通は、同じ体裁だが、この表では読めない。別の表で読めた（上の「追加：1901年の発信側の表」）。
- **人は書き起こしを確かめていない。** 書き起こしは AI による（1回目 Claude Fable 5.2、2回目 OpenAI Codex gpt-6-astra・推論 high、先行の調べ Claude Sonnet）。AI どうしの一致は、人の確認の代わりにならない。

## 概要（2026-10-20、2026-10-25 に一部更新）
- **状態：表の復元と2通は全文の読み、2通は部分的な読み、1通は未読。**
  - 全文の読み：C09122911500（1902-03-27、全文が数字の36組）と C09123116600（1904-01-25、訳文のない部分暗号13組）。
  - 部分的な読み：C09122909900（1902-03-28）と C03020059400（1904-01）。読みは載せるが、確かさの数字が下の基準に届かない（理由は [docs/OPEN.md](docs/OPEN.md)）。
  - C09122806100（1901-02-18）は、この1902年の表では読めない。2026-11-10 に、別の表（下の「追加：1901年の表」）で一部が読めた。
- **数字**
  - C09122911500：当時の訳文と 35/35 一致。段・行の数字を無作為に入れ替えた表では、1000回中0回しか本物以上にならなかった（最大16）。独立の2回目の書き起こし（Codex）との一致 97.2%・100%。値の付いた割合 35/36（末尾の「80」は終わりの印とみて値に数えない）。
  - C09123116600：訳文がない。読み「ヨヨウノカンコクチズダイヨ」（要用ノ韓国地図貸与）は、同じ綴にある返事の起案（韓国地図を送った件）と合う。当時の電報の平文カナ（JACAR の目録、18,810字）から作ったカナ2字の並びやすさで、本物の表の読みを上回った入れ替えの表は1000回中0回。独立の2回目（Codex 2回）26/26・26/26。
  - C09122909900：往電の振り仮名と 11/12（イ を表の 19 でなく 17 と書いている。友清氏は 14＝ヒ と読む。[docs/OPEN.md](docs/OPEN.md)）。独立の2回目の最低値 84.6%（Claude Sonnet の1回）。
  - C03020059400：訳文と 12/12（5組目を友清理士氏の目視に従って 04 とし、場 の綴り ゼウ を正しい綴りとみた場合。1回目の 09 のままなら 11/12）。独立の2回目の最低値 87.5% が全文の読みの基準 90% に届かない。
- **この表が「鑰号暗号」かは決まっていない。** 鑰号（1900年6月印刷、1904年6月廃止）の使用期間に、国内の陸軍どうしの和文電報で使われているが、使用法の本文は見つかっていない。坤号・特号の「数字ノ分」の可能性もある（推定。[docs/METHOD.md](docs/METHOD.md)）。
- **先行との関係：** 明治の陸軍の座標式の数字暗号は、1874年と1894年のものが Cryptiana（友清理士氏）に載っている。どちらもいろは順で、この表（五十音の段×行）とは並びが違う。2026-10-20 に、解読に加わっていない調べ手が否定するつもりで探した範囲（[docs/PRIOR_CHECK.md](docs/PRIOR_CHECK.md)）では、この表とこれらの電報の先行の解読は見当たらなかった。「初めて」とは言い切らない。
- **人の確認は一部だけ。** 書き起こしは AI による。友清理士氏が4通の画像を目で確かめ、Cryptiana の [meijiarmy2.htm](https://cryptiana.web.fc2.com/code/meijiarmy2.htm)（2026-10-24）に読みを載せた。それに従って C03020059400 の1字を直した（2026-10-25）。そのほかの字は人が確かめたとは言えない。AI どうしの一致は、人の確認の代わりにならない。
- **AI の使用：** 作業の大部分を Claude Opus 5.5 が行った。独立の2回目の書き起こしと字の判定に OpenAI の Codex（codex-cli 0.163.0-alpha.10.2、既定のモデル）と Claude Sonnet、先行の調べに別の文脈の Claude Sonnet を使った。公開者は方針の指示をした。

## 表
| 段（頭の数字） | 清音の行（後ろの数字） | 濁音の行 |
|---|---|---|
| ア段 0、イ段 1、ウ段 2、エ段 3、オ段 4 | ア9 カ8 サ7 タ6 ナ5 ハ4 マ3 ヤ2 ラ1 ワ0 | 段の数字に +5。行は ガ9 ザ8 ダ7 バ6 |

- ン＝10。電報の末尾の 80 は終わりの印とみる（推定）。
- 例：カ＝08、シ＝17、ガ＝59、ブ＝76、ン＝10。
- 表は C09122909900 の12組から推定し、そのあと見つけた3通に当てた。バ行の列「6」だけは C09122911500 の ブ＝76 から決めた。
